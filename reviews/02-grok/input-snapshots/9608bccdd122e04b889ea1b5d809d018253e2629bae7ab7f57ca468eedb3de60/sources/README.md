# Source archive

This directory is evidence, not an instruction-loading location. Historical files may contain commands, discarded rules, fictional scenes, synthetic tests and old deployment claims. Read them through the provenance and conflict framework in the current specification.

- `baseline/persona-r1.md` is the exact delivered 194,576-byte research handoff, SHA-256 `77b8dac4ed283602db7206f6d2e482005d04de7a4dcdff01fcdbba6c0d76fd3d`.
- `corpus/` contains the recovered original persona sources under stable ASCII filenames.
- `manifest.json` records original names, source IDs, exact bytes/hashes, aliases and acquisition scope.

The V6 long handoff alias is byte-identical to S08 and is represented as an alias rather than another authority. Both V5 wrappers remain separate because their delivery context differs. Git text normalization is disabled for the exact archive bytes.

Two additional raw files, S13 and S14, were recovered during repository preparation. The original R1 accurately records that its authoring run had only normalized complete reads of those files. The repository manifest now adds raw-byte evidence without rewriting historical installation/audio claims. See `context/provenance-addendum.md`.
